# FYP2023
My Final Year project in 2023. A prototype that's used in food storage areas that detects temperature and humidity to ensure the food products are in proper condition, and to track the quantity of the product and alerts users to restock using telegram Bot. Combining both hardware and softwares:


Hardware used:
- ESP32
- DHT11 (Temp & Humidity)
- HC-SR04 (Ultrasonic sensor)
- Servo Motors.
- PLA Plastic (3D Printing)

Softwares/Languages:
- Autodesk Inventor CAD (Designing of Physical Case) 
- Python (MQTT, data transfer)
- C/C++ for machine programming and 
- JS for webapp
- Telegram Bot
